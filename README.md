# All To DSD Core

FLAC / WAV → DSF（DSD64/128/256）转换器，完整复刻 FiiO JM21 播放器
「All To DSD」功能的数字处理链。

处理链自设备固件逆向得出，并与真机行为完成了**双重验证**：
数字域逐字节对拍（18 组黄金向量 × 三层）+ 真机模拟输出频谱实验。
细节方法不在本仓库公开。

## 下载

直接使用 `build/` 下的 `flac2dsf.exe`（Windows x64，静态链接，无运行时依赖）。

## 用法

```
flac2dsf [options] <in.flac|in.wav> [out.dsf]
```

| 选项 | 说明 |
|---|---|
| `-r, --rate N` | DSD 倍率：64（默认）/ 128 / 256 / 512 |
| `--jm21` | **JM21 真实路径**：与固件逐字节对拍验证的处理链（见下） |
| `--jm21-mode N` | shaper 档位：0 = 8 抽头（设备低档位默认）、1 = 6 抽头、2 = 4 抽头（设备高档位默认） |
| `--arg6 N` | 量化器驱动参数（真实设备路径恒为 0，一般无需修改） |
| `-g, --gain X` | 增益，`db` 后缀（默认 -3 dB）或 `x` 线性。**普通路径请保留默认 -3 dB + 0.05 抖动**（防滤波过冲击穿 1-bit 级）；只有 `--jm21` 路径才用 `--gain 0dB -d 0` 对齐设备 |
| `-d, --dither X` | TPDF 抖动（默认 0.05，0 关闭） |
| `--gain 0dB -d 0` | **与设备工作点严格一致的参数组合** |
| `--stream` | **实时流式处理**：读裸 PCM（文件或 stdin），边到边转 DSD。参数
  `--pcm-bits` / `--pcm-channels` / `--pcm-rate` 声明输入格式 |
| `--web` | 启动本地网页界面（见 [All_To_DSD_网页工具](../All_To_DSD_网页工具)） |
| `--no-tags` | 不复制 FLAC 标签到 DSF |
| `-q, --quiet` | 静默 |

其余插值器/滤波器细节参数见 `flac2dsf --help`。

## JM21 真实路径

`--jm21` 启用从设备固件逆向得到的处理链：

```
int32 立体声 PCM（8 B/帧）
  → 归一化（÷2³¹）
  → 5 级零插入 + 双二阶滤波（×32）
  → 固件 N-抽头 1-bit 量化器（mode 0/1/2 = 8/6/4 抽头，驱动恒定 d8=16）
  → 1-bit 中间缓冲 → 8:1 MSB-first 打包 → [A][B] 交织
  → DSD64 码流（2.8224 MHz）
```

要点：

- **mode 0** 对应设备低档位默认、**mode 2** 对应设备高档位默认；
  `d8 = 16` 与 mode 无关（由独立的设备参数决定，实测恒为 16）。
- 设备工作点：0 dBFS 输入 → 量化器驱动 0.5，正处于噪声整形的小信号边界。
- **复现设备行为请使用 `--gain 0dB -d 0`**；默认的 -3 dB / 0.05 抖动是听感优化，会偏离设备工作点。
